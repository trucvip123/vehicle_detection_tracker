🎯 YOUR NEXT 3 STEPS
════════════════════════════════════════════════════════════════════════════

STEP 1: Install Docker Desktop (10 minutes)
────────────────────────────────────────────

1. Download: https://www.docker.com/products/docker-desktop
2. Run the installer
3. Restart your computer
4. Verify in PowerShell:
   
   docker --version


STEP 2: Enable NVIDIA Container Runtime (5 minutes)
──────────────────────────────────────────────────

1. Open Docker Desktop
2. Go to: Settings → Resources → WSL Integration
3. Click the toggle to enable available distributions
4. Click "Apply & Restart"
5. Verify in PowerShell:
   
   docker run --rm --gpus all nvidia/cuda:12.6.0-runtime-ubuntu22.04 nvidia-smi
   
   Expected: Your GPU info (GTX 1650)


STEP 3: Build & Test (15 minutes)
─────────────────────────────────

Copy-paste INTO PowerShell:

1️⃣ Build Docker image:
   
   cd D:\TrucNV\vehicle_detection_tracker
   docker build -f Dockerfile.gpu -t vehicle-detector:gpu-latest .

2️⃣ Test GPU in container:
   
   docker run --rm --gpus all vehicle-detector:gpu-latest nvidia-smi

3️⃣ Test RTSP streaming:
   
   docker run --rm --gpus all `
     -v ${PWD}:/app `
     vehicle-detector:gpu-latest `
     python quick_rtsp_test.py

   Expected output after ~10 sec:
   ✅ RTSP connection established!
   Frame 256: ... FPS: 25.5
   🟢 RTSP PIPELINE WORKING SUCCESSFULLY!

💡 TIPS
════════════════════════════════════════════════════════════════════════════

1. First build takes 5-10 min (pulls images, installs packages)
   - Subsequent builds are faster

2. If build fails with "requirements.txt not found error"
   - It will fall back to quick_rtsp_test.py (that's OK)

3. If NVIDIA runtime fails
   - Ensure Docker Desktop is fully restarted
   - Try: "Restart" from Docker Desktop→Taskbar

4. RTSP test might take 10-20 seconds to start
   - Don't interrupt, it's connecting to camera

5. GPU memory might show as "0" initially
   - This is normal, it allocated on demand


❓ WHAT IF IT DOESN'T WORK?
════════════════════════════════════════════════════════════════════════════

Error: "docker: command not found"
→ Docker not installed OR terminal not restarted
→ Solution: Restart PowerShell & reinstall Docker if needed

Error: "NVIDIA runtime not available"
→ Docker → Settings → Resources → WSL Integration → toggle ON
→ Then "Apply & Restart"

Error: "Cannot open RTSP stream"
→ Inside container: ping aicamera.serveminecraft.net
→ Or test with VLC: Media → Open Network Stream

Error: "Out of GPU memory"
→ Container limit is 4GB, should be enough
→ Check docker-compose.gpu.yml if needed
